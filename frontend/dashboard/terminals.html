Receptionist Desktop enrolment

A front desk PC can be enrolled two ways: install the issued desk key into this browser (below), or register this browser’s address for the front desk workstation (the registry row action). With a registered address, front desk staff sign in with their email and password alone — nothing to type. Operational staff cannot sign in anywhere else; management roles sign in anywhere as before.

Checking this browser’s address…

An administrator registers the address of the front desk PC itself, never a phone or laptop: any device arriving from a registered address is treated as that desk.

Approved device (survives an address change)

A desktop key and a registered address both stop working when the desk’s IP changes — which is what happens after an unexpected power cut or router restart. An approved device is bound to this browser and to one staff account instead of to an address, so the same browser keeps working from a new address, and the address change is recorded for the administrator to review. Every sign-in still needs that staff member’s own password.

Only the digest is stored on the server, so nobody — including an administrator — can read the token back. If it is lost, approve the browser again to issue a new one.
