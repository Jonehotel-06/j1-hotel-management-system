Front Desk desktop & attendance security

When set, staff who must use the Receptionist Desktop must also sign in, refresh, and clock attendance from this address — in addition to the existing desktop key or registered workstation address. Enter one address (102.89.34.7), a whole network (102.89.34.0/24) when the provider keeps reassigning the desk's public address, or several separated by commas. Leave blank unless you are pinning the front desk to one network; management accounts (administrator, manager, general manager) are exempt and keep working from anywhere. Prefer registering the desk's address on the workstation (Staff → Workstations) when you only need to identify that one PC. Changing this value is an administrator settings change — no code change is needed.
Read this ON the Front Desk desktop and use that value: it is the address the server saw for the browser you are reading this in, right now. A phone on mobile data gets a new address as the network changes, and some carriers share one address between many devices — so a value read on a phone is not a desk address. If the address changes every time you reload this page, it is the hosting platform's proxy rather than the desk, and registering it will never work.
