# Selective rollback

Save original versions before applying any file. Compare `UPDATED_FILES_MANIFEST.md` and apply each file separately at its exact repository-relative path; never replace the whole project. Restore prior versions of `frontend/js/api.js`, `frontend/dashboard/accounting.html` and `frontend/dashboard/barcode-labels.html` from your backup or the reviewed Git revision if reverting. Remove the newly added `frontend/dashboard/menu-print.html`, policy command and two new test files if reverting them. There are no new migrations to reverse and no production database was changed.

If the policy command was run on your own installation, do **not** delete the resulting policy if approvals reference it. Review it with finance administration and preserve approval audit evidence. Check dashboard and Accounting figures independently after rollback. Never flush a database or rewrite historical money/stock transactions to complete rollback.
